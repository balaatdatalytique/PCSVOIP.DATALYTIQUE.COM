# 🚨 SYSTEM PROMPT — HARD RULES + IMPLEMENTATION TASKS  
**Project: Go-based AI-Driven CMS Web Server**

---

## 🔴 HARD RULES (MANDATORY – NO EXCEPTIONS)

1. **BUILD MUST ALWAYS WORK**
   - The project MUST compile successfully using `make build`.
   - DO NOT leave incomplete code or placeholders.
   - DO NOT leave TODOs for core functionality.

2. **BINARY OUTPUT LOCATION**
   - All compiled binaries MUST be placed in `./bin`.
   - If `./bin` does not exist → CREATE it.

3. **STATIC SERVER MUST FUNCTION FULLY**
   - MUST correctly serve:
     - `.html`, `.css`, `.js`, images, fonts, all static assets
   - MUST return correct MIME types (especially for `.js`)
   - MUST NOT break relative paths of the existing website

4. **PORT CONFIGURATION IS MANDATORY**
   - MUST accept `-port` argument from CLI
   - MUST run with default port if not provided
   - Example:
     ```
     ./bin/webserver -port 8080
     ```

5. **ADMIN MODULE SECURITY (NON-NEGOTIABLE)**
   - `/admin` MUST ALWAYS be protected
   - NO unauthenticated access allowed
   - MUST implement:
     - login
     - session management
     - authentication middleware

6. **FILE SYSTEM SAFETY (CRITICAL)**
   - MUST restrict file edits ONLY to approved content directory
   - MUST prevent:
     - path traversal (`../`)
     - arbitrary file access
     - system file modification
   - MUST validate every file operation

7. **NO DIRECT FILE OVERWRITE**
   - BEFORE saving any file:
     - MUST create backup
     - MUST validate content
   - ONLY THEN allow overwrite

8. **AI OUTPUT CONTROL**
   - AI-generated content MUST NOT be auto-published
   - MUST go through:
     - preview
     - admin approval
   - MUST allow rollback

9. **PROVIDER ABSTRACTION (MANDATORY)**
   - DO NOT hardcode OpenAI / Grok / Anthropic
   - MUST implement provider interface layer
   - MUST allow switching providers without code rewrite

10. **PROJECT STRUCTURE DISCIPLINE**
   - MUST follow modular structure
   - NO monolithic single-file server
   - MUST separate:
     - routing
     - auth
     - CMS logic
     - AI integration
     - file services

11. **NO ROOT DIRECTORY CLUTTER**
   - DO NOT dump files in root
   - Maintain clean structure

12. **PRODUCTION-QUALITY CODE ONLY**
   - Clean
   - Readable
   - Maintainable
   - No hacks
